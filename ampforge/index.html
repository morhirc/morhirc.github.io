AmpForgeとは

AmpForgeは、 Windows・Linux・macOSに対応した 無料・オープンソースの ギターアンプシミュレータ・エフェクトプラグインです。

複数のプラグインを別々に組み合わせるのではなく、 ひとつのプラグイン内部に ペダルボード、アンプ、キャビネット、各種エフェクトをまとめています。

VST3、LV2、CLAPに対応し、 環境によってはStandaloneアプリとしても利用できます。

最新版をダウンロード GitHub Repository

主な特徴

19種類の内部モジュール

Noise Gate、Compressor、Wah、Amp、 Cabinet、Delay、Reverbなどを自由に並べ替えられます。

NAM対応

Neural Amp Modelerの .namキャプチャファイルを読み込んで利用できます。

4種類のAmp Type

Modern、Vintage、Crunch、Hi-Gainの 4種類のアンプ特性を選択できます。

ドラッグ＆ドロップ

ペダルを追加し、 ドラッグ操作で自由に並べ替えられる ペダルボードUIを備えています。

ボーカルエフェクト

AutotuneやDe-esserを搭載し、 ギター以外のボーカル処理にも利用できます。

プリセット

Factory Presetに加え、 カスタムプリセットの保存・更新・ Import / Exportにも対応しています。

A/B比較

現在の設定をA/Bスロットへ保存し、 音作りを比較できます。

チューナー内蔵

入力信号を直接解析する 内蔵チューナーを利用できます。

Windows版

Windows向けには、 GitHub Releasesから AmpForge-Setup.exe が配布されています。

Windows版インストーラーでは、 VST3、CLAP、LV2形式をインストールできます。

現時点ではWindows向けStandalone版は提供されていません。 WindowsではDAW内部のVST3 / CLAP / LV2として利用します。

NAM / Cabinet IR

AmpForgeでは、 Neural Amp Modelerの .nam ファイルを読み込めます。

また、Cabinetモジュールでは スピーカーキャビネットのImpulse Responseを WAVファイルとして読み込めます。

NAMモデルやCabinet IRはAmpForge本体には含まれていないため、 利用者自身で用意します。
